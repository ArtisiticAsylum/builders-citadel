# Start Here

**New to this? One idea first.** You've used an AI chat box before. The only new thing here is that some AI *apps* can be handed a folder on your computer — and once one has this folder, it can read and write the files inside it for you. That's the whole trick. Everything below is just typing into a chat box.

Prefer a printed sheet? `START-HERE-quick-start.pdf` (in this folder) is the same thing on two pages.

Welcome to your Citadel. The path, start to finish:

1. **Park this folder somewhere with version history** — OneDrive, Dropbox, iCloud Drive, or git. That history is your recovery route if the rules file ever gets damaged. Don't leave it loose on the desktop.
2. **Get an AI app that can be given a folder** (~10 min). The *website* version of an AI can only see what you paste into it; the *app* is the one that can work in a folder. Claude Desktop with Cowork does this (it needs a paid plan); Claude Code does too if you're comfortable in a terminal. Install it, sign in, then point it at this folder and allow it to work here. You only do this once.
3. **Skim `CLAUDE.md`** (5 min) — the rules any AI must obey in this vault. You don't have to memorize it; just know what your AI is promising you.
4. **Type this into the chat box: "Run SETUP.md."** That's it — an ordinary message, except your AI can now see this folder, so it knows what `SETUP.md` means. It interviews you one question at a time (mostly multiple choice) and builds everything as you answer: your North Star, streams, Meta-Map, email table, rosters, Tower HQ, and schedules. About 30 minutes. Stop and resume whenever — it remembers.
5. **Next morning** — read your first brief, glance at `Tower-HQ.md`, tick something on `Action-Tracker.md`. That loop is the whole system.

**Just want a look first?** Open `Citadel-Game.html` in any browser, watch `docs/assets/citadel-deep-dive.mp4` (five minutes, every part explained), or read `GUIDE.md`. No account, no install, nothing to undo.

Want automation (auto-sent briefs, nightly research, HQ refresh)? `02-Comms/Workflows/` has the plain-English guide, copy-paste prompts, and an n8n starter workflow.
