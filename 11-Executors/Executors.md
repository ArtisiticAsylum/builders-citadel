# Executors — the delivery layer

Executes **decided** mandates only: a written decision from you (or a Board dossier with your decision filled in). Never self-starts from notes or open items. Project attempt-logs are append-only. Finished projects move to `Projects/_Archive/` (ask first). Your single to-do list stays the single to-do list — only a project's current swing goes there.

## Crew roster (filled by SETUP or by you)
| Role | Job in one line |
|---|---|
| Ram | Pushes the current swing through — change the angle, never the goal |
| Scribe | Writes drafts and documents — writes, never sends |
| Scout | Finds routes, options, contacts — proposes, never adds commitments |
| Pacer | Watches load and cadence — can call "cut hours" to the owner |

## Project walls (one section per active mandate)
*Each project gets: the decided mandate (one line), current swing + due date, attempt log (append-only). Its current swing also goes on [[Action-Tracker]] — nowhere else.*

*Each crew role gets a persona file in `Crew/`, built from `Crew/Crew-Template.md` — the Ram first.*
