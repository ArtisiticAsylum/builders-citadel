# The Board

A cross-checking layer: a handful of advisor "seats" (personas grounded in your actual streams) that stress-test big decisions. Sessions run **only on your live ask** — never from a schedule, tag, or note. Advisor lessons-logs are append-only. The board recommends; **you decide**.

## Seat roster (filled by SETUP or by you)
| Seat | Job in one line | Persona file |
|---|---|---|
| Chair | Runs the meeting, forces a recommendation, records dissent | |
| Operator | Execution reality: time, sequence, "what breaks first" | |
| Guardian | Protects health, relationships, self-respect — can veto pace | |
| Treasurer | Money truth: cost, runway, "what does this return" | |

*Rename or add seats to fit your life. Each seat gets a persona file built from `Advisors/Seat-Template.md` when first convened — build the Chair first and deepest. Zero dissent in a board session is a warning sign, not a success.*
